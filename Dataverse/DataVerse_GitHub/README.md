# DataVerse

An interactive CSV data visualization and exploration application built with React and D3. Features numeric-column selection, k-means clustering, outlier detection, and a record details panel.

## Run locally

1. Install Node.js (LTS).
2. Open a terminal in this project folder.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL shown in your terminal (usually http://localhost:5173).

## GitHub

Create a new repository named `DataVerse` and upload the files in this folder (not the ZIP itself). The `src` directory and `package.json` are required.

## Notes

This package contains the available DataVerse JSX source file. It does not claim to include a separately developed cinematic redesign or a published site. Dataset processing runs in the browser.
