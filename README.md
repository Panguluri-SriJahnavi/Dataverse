# DataVerse – Interactive Data Visualization

DataVerse is an interactive web application designed to explore, visualize, and analyze datasets.

## Features
- CSV dataset upload
- Interactive data visualization using D3.js
- K-Means clustering
- Outlier detection
- Selection of numerical features
- Interactive data point exploration
- Cluster statistics and correlation analysis

## Technologies Used
- React.js
- JavaScript
- D3.js
- HTML and CSS

## Project Objective
To simplify data exploration by transforming raw datasets into meaningful interactive visualizations and helping users discover patterns, clusters, and anomalies.
